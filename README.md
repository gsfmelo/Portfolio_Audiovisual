## 💡 Sobre o Projeto

Este repositório contém o código-fonte do meu portfólio profissional. Diferente de templates prontos, o site foi projetado do zero para refletir uma identidade visual cinematográfica e editorial (inspirada em roteiros e marcações de câmera), rodando sobre uma arquitetura web moderna, rápida e escalável.

O objetivo é apresentar não apenas os meus cortes e direções de vídeo, mas também meu olhar lógico para otimização de processos e desenvolvimento de soluções.

## 🛠️ Stack Tecnológico

O projeto foi construído utilizando as melhores práticas do ecossistema front-end atual:

*   **Framework:** [Next.js](https://nextjs.org/) (React)
*   **Estilização:** [Tailwind CSS](https://tailwindcss.com/) (com paleta de cores customizada em variáveis CSS)
*   **Formulário de Contato:** Integração com [Formspree](https://formspree.io/) via requisições assíncronas (Fetch API).
*   **Hospedagem & CI/CD:** [Vercel](https://vercel.com/) (Deploy contínuo integrado ao GitHub).

## ✨ Features e Decisões de Design

*   **Cinematic UI:** Elementos de interface inspirados no audiovisual, como cantoneiras de *viewfinder*, detalhes técnicos (REC // 24FPS) e tipografia mista (Libre Caslon para elegância editorial e JetBrains Mono para toques técnicos).
*   **Performance First:** Utilização de fontes nativas otimizadas (`next/font`) e imagens responsivas.
*   **UX Imersiva no Contato:** O formulário de contato simula um roteiro (INT. CAIXA DE ENTRADA - DIA) e possui um estado de sucesso customizado com animação "Fade to Black".
*   **Animações Fluidas:** Efeitos de `FadeIn` no scroll e barras deslizantes contínuas (*Marquee*) construídas com CSS puro para parceiros e clientes.
